Cita Rechazada

Esta solicitud fue rechazada por el médico. El bloque horario correspondiente ha vuelto a quedar disponible para nuevas solicitudes.

¿Qué significa cada estado?
PENDIENTE
La solicitud está esperando la decisión del médico. Mientras se encuentre pendiente, ese horario permanece reservado y ningún otro paciente puede solicitarlo.
CONFIRMADA
El médico aceptó la cita. El horario continúa reservado para ese paciente.
RECHAZADA
El médico rechazó la solicitud. El horario queda nuevamente disponible para otros pacientes.
CANCELADA
La cita fue cancelada. El horario vuelve a quedar disponible para una nueva solicitud.
